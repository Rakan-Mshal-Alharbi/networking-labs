# LAB 01 — Basic LAN Configuration and Connectivity Testing

## Project Overview
Built a basic Local Area Network (LAN) using Cisco Packet Tracer.

## Devices
- 2  PCs
- 1 Cisco 2960 Switch

## IP Addressing

| Device | IP Address | Subnet Mask |
|---|---|---|
| PC0 | 192.168.1.2 | 255.255.255.0 |
| PC1 | 192.168.1.3 | 255.255.255.0 |

## Configuration
- Connected both PCs to the switch.
- Configured static IP addresses.
- Set the switch hostname to SW1.
- Configured access ports Fa0/1 and Fa0/2.
- Verified learned MAC addresses.

## Testing
Used the ping command to test connectivity between PC0 and PC1.

**Expected result:** Successful ICMP replies.
